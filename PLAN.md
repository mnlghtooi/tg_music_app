## Порядок этапов — не менять без отдельного решения

### Этап 1. Плейлист из трёх тестовых треков — ЗАВЕРШЁН (18.10.2026)
- [x] Три разные тестовые мелодии.
- [x] Play / Pause / Next / Previous.
- [x] Автоматическое переключение после окончания трека.
- [x] Очередь и название текущего трека.
- [x] Media Session: проверить системное управление на экране блокировки и с Bluetooth-наушников.
- [x] Журнал событий для диагностики.
**Критерий завершения:** ручное и автоматическое переключение проверены на iPhone, включая блокировку экрана. Если iOS/Telegram приостанавливают скрипты, фиксируем ограничение, не объявляем этап успешно завершённым.


**Проверено пользователем:** ручное и автоматическое переключение, воспроизведение при блокировке экрана, кнопки Next/Previous на экране блокировки после v0.2.1. Тест выполнен на одном iPhone; не означает универсальную гарантию для всех версий iOS.

## Принципы разработки
1. Двигаться строго по этапам, следующий начинать после проверки предыдущего пользователем на iPhone.
2. Не добавлять лишние серверы и музыкальные сервисы раньше времени.
3. Изменения хранить в GitHub; фиксировать проверенные результаты и ограничения.
4. Не считать фоновое воспроизведение гарантированным для всех версий iOS/Telegram на основании одного теста.
5. Права на музыкальные произведения и условия внешних API учитывать до публичного распространения.
