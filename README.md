# Music Lab — Telegram Mini App

Тест фонового воспроизведения аудио на iPhone внутри Telegram.

## Развёртывание
1. В репозитории открой **Settings → Pages**.
2. В **Build and deployment** выбери **Deploy from a branch**, **main**, **/(root)** и **Save**.
3. Сайт будет доступен по адресу https://mnlghtooi.github.io/tg_music_app/
4. В Telegram открой **@BotFather** → /setmenubutton → выбери своего бота → вставь адрес сайта и подпись «Music Lab».
5. На iPhone открой приложение из меню бота, нажми Play, заблокируй экран на минуту, вернись и проверь воспроизведение.

## Детали
- Один файл index.html, без сервера или внешнего музыкального API.
- 96-секундный синтезированный WAV генерируется прямо на устройстве и воспроизводится тегом HTML5 audio в цикле.
- Можно также выбрать собственный MP3/M4A через кнопку выбора файла.
- Это проверка возможностей WebView на конкретном устройстве, а не гарантия фонового воспроизведения на всех версиях Telegram/iOS.
- Бот-токен в репозиторий не нужен.
